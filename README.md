# Gomi Locas

Sitio de Gomi Locas con un carrusel de cuatro mezclas, fondos y decoraciones propios, transiciones animadas y navegación con flechas.

## Pedidos

1. Elige una mezcla y toca **Comprar ahora**.
2. Selecciona el tamaño del vaso: chico ($35), mediano ($65) o grande ($90).
3. Escoge Tajín, chamoy, Miguelito y cualquier extra que quieras indicar.
4. Agrega el vaso al carrito. Puedes ajustar cantidades, quitar artículos o seguir agregando.
5. Envía el pedido completo a WhatsApp desde el carrito.

## Abrir el sitio

Abre `index.html` en un navegador. No requiere instalación ni dependencias de compilación. Las imágenes, el logo y los estilos están incluidos en esta carpeta.
